# Assignment 1 - Pass the Pigs

This program simulates a simplified version of David Moffat’s dice game Pass the Pigs. It involves using all the basic programming language facilities: loops, conditions, arrays, primitive types, etc. The game can be played with a minimum of 2 players and a maximum of 10 players. The players are arranged in a circle and take turns rolling a die (the die is called Pig) to earn points. Rolling Side earns the player 0 points and his turn is officially over. The Pig then gets passed to the next player. Rolling either Razorback or Trotter earns 10 points for the player. Rolling Snouter earns 15 points. Lastly, rolling Jowler earns 5 points. The game ends when any player has earned 100 or more points.

## Building

Build the program with:

make

## Running

Run the program with: 

$ ./pig
